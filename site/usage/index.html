Project guide

Use the CLI

Run Holehe locally and read its output with care.

Basic command

holehe example@example.com

Replace the example with an address you are authorized to check. The CLI performs network requests to supported services. Avoid repeated or bulk checks.

Module output

The upstream README describes fields including name, exists, rateLimit, emailrecovery, phoneNumber, and others. Recovery details may be partially masked.

A positive or negative result reflects the service response at that moment. Rate limits and changing service flows can affect it.

See the upstream Quick Start for the Python integration example and current CLI behavior.
