Understand where an email may be registered.

Holehe checks registration signals on supported services through their account recovery flows. This guide explains the command-line project and its limits. It does not run checks in your browser.

How the project works

1. Install locally

Use Python and the published package or build from source.

Installation steps →

2. Run the CLI

Supply an email address at the command line. Individual service modules produce signals that may be incomplete.

CLI and output →

3. Interpret carefully

Services can change behavior or rate limit checks. A signal is not proof of account ownership.

Built around the existing project

The Python package remains the source of functionality. This static guide has no backend, account lookup endpoint, analytics, or email submission form.
