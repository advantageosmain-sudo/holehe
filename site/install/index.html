Install Holehe

Install the Python command-line package.

Requirements

Python 3 and pip. The upstream README also documents Docker installation. Check your local Python and pip versions before installing.

python3 --version
python3 -m pip --version

From PyPI

python3 -m pip install holehe
holehe --help

If your Python installation requires a virtual environment, create and activate one first:

python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install holehe

On Windows, activate it with .venv\Scripts\activate.

From source

git clone https://github.com/megadose/holehe.git
cd holehe
python3 -m pip install .

The original project also includes a Dockerfile. See the upstream Docker instructions.
